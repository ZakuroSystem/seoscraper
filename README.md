# seoscraper

A tiny example application demonstrating a simple SEO analysis web UI.

## Setup

```bash
pip install -r requirements.txt
python app.py
```

Then open <http://localhost:5000/> in your browser.

## Features

- Paste a URL or text to analyze.
- Tokenizes text, filters stopwords and counts word frequencies.
- Displays results in a rich web UI using Chart.js.
